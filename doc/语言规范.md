# 汉语言 语言规范（阶段一~六 + 扩展特性：词法/语法/语义/IR/后端/运行时 冻结）

> 本文件冻结「词法层」「语法层」「语义层」「中间表示层」「后端/链接/运行时」。
> 实现：纯 C11，自研前端 + 自研 x86-64 后端，产出无 CRT 依赖的独立 Windows exe。
> 扩展特性：默认参数、可变参数、闭包/匿名函数、字典字面量与成员访问糖、多文件导入，均已实现并纳入本规范。

## 1. 源文件

- 编码：UTF-8。扩展名约定 `.汉`。
- 允许 UTF-8 BOM，词法阶段自动跳过。
- 换行：`\n`、`\r\n`、`\r` 一律归一为 `\n`（读入阶段完成）。
- 换行在词法层产出「换行」记号，作为语句分隔符；阶段二的解析器负责忽略多余换行。

## 2. 空白与注释

| 形式 | 说明 |
|---|---|
| 空格 / 制表符 / 换页符 / 全角空格 U+3000 | 忽略，仅用于分隔 |
| `#` … 行尾 | 行注释 |
| `/* … */` | 块注释，**允许嵌套**（深度计数） |

## 3. 全角标点归一

归一仅在“代码上下文”生效；**字符串内部保持原样**（`“你好，世界”` 中的逗号不会被改写）。

### 3.1 全角 ASCII（U+FF01–U+FF5E）

`！＂＃＄％＆＇（）＊＋，－．／０-９：；＜＝＞？＠Ａ-Ｚ［＼］＾＿｀ａ-ｚ｛｜｝～`
→ 对应 ASCII 字符（码点减 0xFEE0）。因此 `１２３`、`ＡＢＣ` 均可用。

### 3.2 中文标点专表

| 中文 | ASCII | 用途 |
|---|---|---|
| `、` U+3001 | `,` | 逗号（列表、实参分隔） |
| `。` U+3002 | `;` | **语句结束符**（中文句号当分号用） |
| `【` `〔` / `】` `〕` | `[` / `]` | 索引、列表字面量 |
| `《` `〈` / `》` `〉` | `<` / `>` | 比较、类型参数占位 |
| `「` `『` / `」` `』` | `"` / `"` | 文字字面量引号 |
| `“` `”` U+201C/D | `"` | 文字字面量引号 |
| `—` `–` (U+2014/2015/2013) | `-` | 减号 / 负号 |
| `…` U+2026 | `.` | 单点；连续 `...` 为可变参数记号 |

### 3.3 全角空格

U+3000 → 普通空格。

## 4. 标识符

- 起始字符：汉字（U+4E00–U+9FFF、U+3400–U+4DBF、U+F900–U+FAFF、U+20000–U+2A6DF、`〇`）、ASCII 字母、`_`
- 后续字符：起始字符 + ASCII 数字
- 示例：`计数器`、`总值`、`x_值2`、`ABC`（可由全角输入）
- 关键字不可作为标识符；同一标识符的大小写/全半角由归一规则决定。

## 6. 字面量

### 6.1 整数

- 十进制 `123`，可用 `_` 分隔：`1_000_000`
- 十六进制 `0xFF`、`0X1F`；二进制 `0b1010`；八进制 `0o17`
- 取值范围：64 位有符号；溢出报错
- 数字后紧跟标识符起始字符（如 `123abc`）报错

### 6.2 小数

- `3.14`、`2.5E+3`、`1e-9`；指数符号 `e/E` 后可带 `+/-`
- 不支持前导小数点 `.5`（`.5` 解析为 `.` 与 `5`）；`1.` 不视为小数

### 6.3 文字（字符串）

- 引号：`"…"`、`“…”`、`「…」`、`『…』`
- 转义：`\n` `\t` `\r` `\\` `\"` `\0`
- 不允许裸换行；跨行需显式拼接（阶段二提供）
- 引号内不做全角归一，任何字符原样保留

## 7. 标点与运算符

| 记号 | 写法 |
|---|---|
| `(` `)` `[` `]` `{` `}` | 分组、索引/列表、字典字面量 |
| `,` `:` `;` | 分隔、类型标注、语句结束 |
| `.` | 成员访问 |
| `->` | 返回类型标注 |
| `=>` | 匿名函数 |
| `...` | 可变参数 |
| `+ - * / % ^` | 算术（`^` 为幂） |
| `= == != < <= > >=` | 赋值与比较 |
| `&& \|\| !` | 逻辑（与关键字同义） |

语句分隔：换行或 `;`（含中文句号 `。`）；连续换行由解析器折叠。

## 8. 诊断格式

```
文件:行:列: 错误: 消息
  源码行
      ^
```

- 行、列从 1 起；**列按字符计**（中文占 1 列，制表符占 1 列）。
- 词法错误类型：非法字符、非法 UTF-8、未闭合字符串、未闭合块注释、数字缺数字、整数溢出、未知转义、数字后紧跟标识符。

## 9. 语法（阶段二冻结）

### 9.1 顶层结构

源文件由若干**顶层声明**组成，声明之间以换行分隔。顶层声明包括：

```text
顶层声明 ::= 导入声明 | 函数声明 | 变量声明 | 常量声明 | 顶层语句
```

**顶层语句**指直接写在模块级别的语句（赋值、打印、表达式等），解析器将其包装为 `DECL_STMT` 节点。

**导入声明**（多文件模块）：

```text
导入 "相对路径.汉"
```

- 路径相对**导入者所在文件**的目录解析；编译期把被导入文件的顶层声明递归展开进当前模块
- 规范化路径去重：同一文件多次导入只展开一次；导入成环时报错
- 被导入模块的顶层语句（如 `打印`）在展开点按序执行
- `从 …` 选择性导入保留未实现

### 9.2 函数声明

```text
函数 函数名(参数列表) -> 返回类型
  函数体
结束
```

- 参数列表：`名字: 类型` 的逗号分隔序列，可为空
- **默认参数**：`名字: 类型 = 默认值`（默认值须为常量表达式）；调用时缺省实参由编译器在**调用点**用声明处默认值常量补齐。带默认值的参数之后不允许再有普通参数
- **可变参数**：参数列表末尾允许一个 `...名字`，函数体内 `名字` 的类型为 `列表`；调用时超出固定形参数量的多余实参自动打包为列表传入。可变参数与默认参数可共存（默认值先补齐，多余实参再打包）
- 返回类型标注可选，省略时返回类型为 `空`；`-> 函数` 为合法的「裸函数」注解（无签名，见 10.3）
- 函数体是语句块，以 `结束` 收尾

### 9.3 变量与常量声明

```text
变量 名字 [: 类型] = 初值     # 类型标注可选，省略则推断
常量 名字 = 初值              # 必须有初值
```

### 9.4 语句

```text
语句 ::= 变量声明 | 常量声明 | 赋值 | 返回 | 如果 | 当 | 对于
       | 跳出 | 继续 | 打印 | 表达式语句 | 语句块
```

| 语句 | 语法 |
|---|---|
| 赋值 | `目标 = 值` |
| 返回 | `返回 [表达式]` |
| 如果 | `如果 条件\n  块\n结束 [否则\n  块\n结束]`（`结束` 与 `否则` 可分行） |
| 当 | `当 条件\n  循环体\n结束` |
| 对于 | `对于 变量 = 起点 到 终点\n  循环体\n结束` |
| 跳出 | `跳出` |
| 继续 | `继续` |
| 打印 | `打印 表达式` |
| 表达式语句 | 表达式 |

- 块一律以 `结束` 收尾（`如果`/`当`/`对于`/`函数` 皆同）
- 语句分隔：换行或 `;`（含中文句号 `。`）

### 9.5 表达式与优先级

优先级从低到高：

```text
赋值 (=)              右结合
逻辑或 (|| / 或)
逻辑与 (&& / 与)
相等 (== !=)
关系 (< <= > >=)
加减 (+ -)
乘除 (* / %)
幂 (^)               右结合；整数指数走平方幂，非整数指数按 e^(y·ln x) 计算
一元 (- ! 非)
后缀 (调用() 索引[] 成员.)
主表达式 (字面量 标识符 (表达式) [列表] {字典} 匿名函数)
```

**匿名函数**（闭包）：

```text
(参数列表) => 表达式
```

- 参数写法和函数声明一致（类型标注可省略）；函数体为单个表达式，其值即返回值
- **按值捕获**：匿名函数引用外层局部变量时，在创建点把变量当前值快照进环境；禁止对被捕获的变量再赋值（语义期报错）
- 函数是一等值：命名函数可直接赋给变量/作实参（编译器自动生成包装函数），闭包与函数值可通过变量间接调用，如 `变量 算子 = 翻倍` 后 `算子(21)`
- 打印函数值输出 `<函数>`

### 9.6 字面量

| 种类 | 示例 |
|---|---|
| 整数 | `42` `0xFF` `0b1010` `1_000_000` |
| 小数 | `3.14` `2.5e3` |
| 文字 | `"你好"` `"你好"` `「你好」` |
| 布尔 | `真` `假` |
| 空 | `空` |
| 列表 | `[1, 2, 3]` |
| 字典 | `{名字: "小明", 年龄: 18}` |

字典字面量的键须为常量文字（标识符键自动视为文字），值可为任意表达式。

**成员访问糖**：`表.名` 等价于 `字典取(表, "名")`，`表.名 = 值` 等价于 `字典设(表, "名", 值)`。成员读取结果的静态类型为「未知」：打印整数值成员可直接 `打印 表.名`；需要按文字等具体类型使用时应改用类型化访问器，如 `字典取文字(表, "名")`。

## 10. 语义与类型检查（阶段三冻结）

### 10.1 类型系统

| 类型 | 写法 | 说明 |
|---|---|---|
| 整数 | `整数` | 64 位有符号 |
| 小数 | `小数` | 64 位浮点 |
| 文字 | `文字` | 字符串 |
| 布尔 | `布尔` | 内部类型，字面量真/假 |
| 空 | `空` | 无返回值 / void |
| 空值 | — | `空` 字面量的类型 |
| 列表 | `列表<元素类型>` | 动态数组 |
| 函数 | — | 参数 + 返回类型 |

- 类型以**结构等价**判定：相同结构的类型共享同一驻留指针，可直接 `==` 比较
- 类型驻留表为 **arena 本地**，随编译单元销毁，避免跨 arena 野指针

### 10.2 类型推断与标注

- 变量声明可省略类型标注，由初值推断类型
- 标注与初值类型不匹配时报错（整数可隐式转为小数）
- 函数参数与返回类型标注可选，省略时参数/返回为未知

### 10.3 检查规则

| 检查项 | 规则 |
|---|---|
| 未定义标识符 | 引用未声明的变量/函数报错 |
| 重复定义 | 同一作用域内同名声明报错 |
| 类型不匹配 | 标注与初值、返回值与函数返回类型不一致报错 |
| 参数数量 | 函数调用实参与形参数量不匹配报错（可变参数除外） |
| 不可调用 | 对非函数类型调用报错 |
| 跳出/继续 | 只能在循环内使用，否则报错 |
| 索引 | 索引操作要求列表类型 |
| 运算符 | 算术要求数值类型，`+` 可用于文字拼接，比较/逻辑返回布尔 |
| 默认参数 | 调用实参可少于形参（缺省项必须有默认值），多于形参仍报错（可变参数除外） |
| 可变参数 | 实参数量不得少于固定形参数；多余实参打包为 `列表` 传给可变形参 |
| 闭包捕获 | 按值捕获外层局部变量；对被捕获变量赋值报错 |
| 裸函数注解 | `-> 函数` 无签名：调用时跳过实参检查，结果类型为「未知」 |
| 列表类型相容 | 两侧均为列表时，任一侧元素类型未知（含裸 `列表`）即相容 |

**函数值**：命名函数标识符在值位置出现时为函数引用（funcref），类型为 `函数`；通过变量调用时按间接调用处理。

### 10.4 作用域

- 采用词法作用域，块级嵌套
- 函数先**预扫描**：所有函数签名先入全局作用域，支持前向引用与递归
- 函数参数在函数体作用域内可见

## 11. 中间表示 IR（阶段四冻结）

### 11.1 形式

三地址码（Three-Address Code），每个指令最多两个源操作数、一个目的操作数。

- 临时值：`%N`（N 从 0 递增）
- 标签：`L N`

### 11.2 指令集

| 指令 | 含义 |
|---|---|
| `%d = 常量` | 整数/小数/文字/布尔常量 |
| `%d = 加载 名字` | 加载变量 |
| `存储 名字 = %s` | 存储变量 |
| `%d = %s1 + %s2` | 算术（加减乘除模幂） |
| `%d = -%s` / `%d = !%s` | 一元负 / 逻辑非 |
| `%d = %s1 == %s2` | 比较（== != < <= > >=） |
| `%d = %s1 && %s2` | 逻辑与/或 |
| `%d = 调用 %callee(...)` | 函数调用 |
| `打印 %s` | 输出 |
| `返回 [%s]` | 函数返回 |
| `跳转 Ln` | 无条件跳转 |
| `如果 %s 跳转 Ln` | 条件跳转 |
| `Ln:` | 标签 |
| `%d = %s1[%s2]` / `%s1[%s2] = %d` | 列表索引读/写 |
| `%d = 列表[...]` | 列表构造 |
| `%d = 字典{...}` | 字典构造（`IR_DICT_NEW` + 逐对 `IR_DICT_SET`，键为常量文字） |
| `%d = %s1.键` | 字典成员读（`IR_DICT_GET`） |
| `%s1.键 = %s2` | 字典成员写（`IR_DICT_SET`） |
| `%d = 闭包 函数(捕获...)` | 闭包对象构造（`IR_LAMBDA_NEW`：16 字节 `{函数指针, 环境指针}`，环境为按值捕获快照，无捕获时环境指针为 0） |
| `%d = 环境加载 #n` | 从 `__env` 读取第 n 个捕获值（`IR_ENV_LOAD`，序号存于 `ival`） |
| `%d = 间接调用 %s(...)` | 闭包间接调用（`IR_CALL_IND`，隐藏第 0 实参为环境指针，由后端从闭包对象取出） |
| `nop` | 空操作 |

扩展特性在 IR 层的其余处理：

- **默认参数**：`IR_CALL` 发射前在调用点用声明处默认值常量补齐缺省实参
- **可变参数**：多余实参先求值，再 `IR_LIST_NEW` 打包为末尾隐式实参；被调函数的最后一个形参槽即该列表
- **匿名函数**：提升为独立函数 `chlam_N`（隐藏第 0 参数 `__env`），创建点发射 `IR_LAMBDA_NEW`；命名函数作值时生成包装函数 `chwrap_N`（同样带 `__env`），保证闭包 ABI 一致

### 11.3 优化

- **常量折叠**：向前扫描 `IR_CONST` 指令，对算术/比较指令的常量操作数直接求值，替换为 `IR_CONST`
- 支持整数与小数的常量折叠（除法除零跳过）

### 11.4 生成

- 顶层语句包装进隐式「主」函数（符号 `__ch_main`）后参与 IR 生成
- `对于` 循环展开为 `当` 循环形式（含循环变量自增）
- 调用实参与列表元素严格「先求值、后发射指令」，保证求值顺序
- `&&` / `||` 在 IR 层展开为短路控制流（分支 + 标签），不做非短路求值

## 12. 编译流水线（既定）

词法 → 语法（AST）→ 语义与类型检查 → 中间表示 → 优化 → x86-64 指令选择 → 寄存器分配 → COFF → 链接（仅导入 kernel32，无 CRT）。

## 13. 后端、链接与运行时（阶段五~六冻结）

### 13.1 目标平台与 ABI

- 输出：Windows x86-64，PE32+，控制台子系统（Subsystem=3）
- 依赖：**仅 kernel32.dll**（导入表 9 个函数），不使用任何 CRT，不生成 `.reloc`（未开启 ASLR）
- 调用约定：Microsoft x64
  - 整数/指针参数：`rcx` `rdx` `r8` `r9`；小数参数：`xmm0`～`xmm3`（与整数寄存器按位置一一对应）
  - 第 5 个及以后的参数从 `[rbp+48+8*(i-4)]` 读取
  - 调用前预留 32 字节 shadow space，栈保持 16 字节对齐
  - 返回值：整数在 `rax`，小数在 `xmm0`

### 13.2 栈帧与寄存器分配

- 采用「栈槽分配 + 寄存器复用」：每个 IR 临时值与局部变量各占一个 8 字节栈槽，`槽偏移 = -8*(槽号+1)`
- 运算时把操作数载入 `rax/rcx`（整数）或 `xmm0/xmm1`（小数），结果写回栈槽；不做跨语句的寄存器驻留
- 生成代码不使用 callee-saved 寄存器（`rbx/rsi/rdi/r12-r15`），因此函数序言只需保存 `rbp`

### 13.3 指令选择

| 语义 | 指令 |
|---|---|
| 整数加减乘 | `add` `sub` `imul` |
| 整数除/模 | `cqo` + `idiv`（商在 `rax`，余在 `rdx`） |
| 整数幂 | 调用运行时 `rt_pow_i64` |
| 小数运算 | SSE2：`addsd` `subsd` `mulsd` `divsd`；模/幂调用 `rt_mod_f64` `rt_pow_f64` |
| 整数转小数 | `cvtsi2sd` |
| 比较 | 整数：`cmp`+`setcc`；小数：`ucomisd`+`setcc`/`setnp` |
| 文字比较/拼接 | 调用 `rt_str_eq` / `rt_str_concat` |
| 分支 | `jmp rel32` / `jcc rel32`（`test eax,eax` 后判零） |
| 调用 | `call rel32`（对导入函数为 `call *disp32(%rip)` 走 IAT） |

### 13.4 符号命名

| 对象 | 符号 |
|---|---|
| 用户函数 `函数 甲` | `chf_甲` |
| 模块级变量/常量 `变量 总值` | `g_总值` |
| 隐式主函数（顶层语句） | `__ch_main` |
| 提升的匿名函数 | `chlam_N`（N 从 0 递增） |
| 命名函数的 funcref 包装函数 | `chwrap_N` |
| 运行时入口（运行时提供） | `rt_entry` |
| 标准库函数 | `rt_*`（见 13.6） |
| kernel32 导入 | `__imp_*` |

**闭包 ABI**：闭包值为 16 字节对象 `{函数指针(+0), 环境指针(+8)}`；所有闭包目标函数（`chlam_*` 与 `chwrap_*`）均带隐藏第 0 参数 `__env`（占 `rcx`），用户参数顺延到 `rdx/r8/r9`（或 `xmm1`~`xmm3`），第 5 个及以后上栈。间接调用时后端从闭包对象取出环境指针装入 `rcx`，再 `call *0(%rax)`。环境为创建点的按值捕获快照（每槽 8 字节）。

### 13.5 目标文件与链接

- 编译器内部对象模型固定四类节：`.text` / `.rdata` / `.data` / `.bss`
- 运行时以 COFF 目标文件（`build/runtime.obj`）嵌入编译器，链接时由自研 COFF 读取器解析：
  - 节表映射、符号表（含 AUX 辅助记录）、字符串表
  - 重定位：`IMAGE_REL_AMD64_REL32`(0x0004) 及 `REL32_1..5`(0x0005~0x0009)、`ADDR64`(0x0001)、`ADDR32NB`(0x0003)
- 链接器把多个模块的同名节合并（**16 字节对齐**：gcc -O2 编译的运行时存在 `movdqa` 等对齐 SSE 访问，仅 8 字节对齐会导致运行期崩溃），重定位公式：
  - `REL32`：`现场 32 位值 = S + A - (P + 4 + N)`，N 取自重定位类型（`REL32_N` → N）
  - `ADDR64`：`S + A + 镜像基址`
  - `ADDR32NB`：`S + A`（RVA）
- 导入表 `.idata` 布局：导入描述符（每项 20 字节）→ ILT → IAT → Hint/Name → DLL 名；模块内符号优先，未定义且以 `__imp_` 开头者视为 kernel32 导入，其余报「未定义的符号」
- PE 布局：镜像基址 `0x140000000`，节对齐 `0x1000`，文件对齐 `0x200`；入口 `AddressOfEntryPoint = rt_entry` 的 RVA

### 13.6 运行时与标准库

运行时（`runtime/runtime.c`）以 `-ffreestanding -nostdlib` 编译，自实现 `memset/memcpy`，仅通过 `__declspec(dllimport)` 调用 kernel32。

`rt_entry`：`SetConsoleOutputCP(65001)` + `SetConsoleCP(65001)` → 注册异常过滤器 → 调用 `__ch_main()` → 控制台输出时暂停等待回车 → `ExitProcess(0)`。

**入口暂停行为**：若进程拥有自己的控制台窗口（`GetConsoleProcessList` 计数为 1，
即双击 exe 或编辑器 F5 新窗口运行的情形），程序结束后先打印
「── 程序结束，按回车键退出 ──」并等待回车，避免窗口一闪而过；
从已有终端或管道启动时不暂停。

**实现**：以「标准输出是否连着控制台」（`GetConsoleMode`）判定，
因此 Windows Terminal 的伪控制台同样会暂停，而管道/文件重定向不会（便于自动化测试）。
程序运行中发生未处理异常时，`SetUnhandledExceptionFilter` 会打印异常代码并同样暂停。
