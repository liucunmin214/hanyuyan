# 汉语言入门教程

> 从零开始学汉语言：一门用中文写代码的静态类型编译型语言。
> 本教程配套示例在 `examples/` 目录，每个都可以直接编译运行。

## 1. 认识汉语言

汉语言让你用自然的中文书写程序：

```text
打印 "你好，汉语言！"
```

- **中文关键字**：`变量`、`如果`、`当`、`函数`、`打印`……并支持同义词（`令`=`变量`、`输出`=`打印`、`若`=`如果`）
- **全角标点自动归一**：`，。（）：`等中文标点直接写，编译器自动识别
- **静态类型 + 类型推断**：类型在编译期检查，大多数情况可省略标注
- **真正的编译**：产出独立 Windows exe，不需要安装任何运行时
- **块用「结束」收尾**：不用大括号，`如果`、`当`、`函数` 一律以 `结束` 结束

## 2. 安装与准备

无需安装，解压即用。目录结构：

```text
汉语言/
├── build/
│   ├── han.exe        # 编译器（命令行）
│   └── hanedit.exe    # 代码编辑器（图形界面）
├── doc/               # 规范、教程、手册
└── examples/          # 本教程配套示例
```

编辑器与编译器二选一使用：

- **图形方式**（推荐新手）：双击 `build\hanedit.exe`，写好代码按 **F5** 编译运行
- **命令行方式**：`build\han.exe 我的程序.汉 -o 我的程序.exe`

## 3. 第一个程序

新建文件 `你好.汉`，输入一行：

```text
打印 "你好，汉语言！"
```

在编辑器里按 **F5**，输出面板显示：

```text
══ 编译 ══
✓ 编译成功
══ 运行 ══
你好，汉语言！
✓ 运行结束
```

`打印` 是最常用的语句，后面跟任意表达式，自动换行。同义词 `输出`、`显示` 效果相同。

## 4. 变量、常量与类型

```text
变量 甲 = 10            # 类型由初值推断为「整数」
变量 乙: 小数 = 2.5     # 显式标注类型
常量 圆周率 = 3.14159   # 常量必须有初值，不可再赋值
```

五种基本类型：

| 类型 | 写法 | 示例 |
|---|---|---|
| 整数 | `整数` | `42`、`0xFF`、`0b1010`、`1_000_000` |
| 小数 | `小数` | `3.14`、`2.5e3` |
| 文字 | `文字` | `"你好"`、`「你好」`、`『你好』` |
| 布尔 | （真/假） | `真`、`假` |
| 空 | `空` | 表示「没有值」 |

整数可以隐式转为小数，其余类型不匹配会在编译期报错。

## 5. 运算符与表达式

```text
打印 1 + 2 * 3      # 7，先乘除后加减
打印 2 ^ 10         # 1024，^ 是幂运算（也支持小数指数：2 ^ 0.5 ≈ 1.41421）
打印 7 % 3          # 1，取余
打印 "你好，" + "世界"   # 文字拼接
打印 3 > 2 与 1 < 5    # 真（与/或/非 即 &&/||/!）
```

比较运算 `== != < <= > >=` 结果是布尔值；`=` 是赋值，`==` 才是判等。

## 6. 控制流

**如果 / 否则**——注意「否则」写在前一个「结束」之后：

```text
变量 分数 = 85
如果 分数 >= 90
  打印 "优秀"
结束
否则
  打印 "继续加油"
结束
```

**当**——条件为真就一直循环：

```text
变量 倒计时 = 3
当 倒计时 > 0
  打印 倒计时
  倒计时 = 倒计时 - 1
结束
```

**对于**——从起点数到终点（含两端）：

```text
变量 总和 = 0
对于 数 = 1 到 100
  总和 = 总和 + 数
结束
打印 总和        # 5050
```

循环里可用 `跳出`（结束循环）与 `继续`（跳到下一轮）。

## 7. 函数

```text
函数 阶乘(数: 整数) -> 整数
  如果 数 <= 1
    返回 1
  结束
  返回 数 * 阶乘(数 - 1)    # 支持递归
结束

打印 阶乘(10)   # 3628800
```

**默认参数**：缺省实参自动用默认值补齐：

```text
函数 问候(名字: 文字, 称呼: 文字 = "同学") -> 文字
  返回 称呼 + "，你好，" + 名字 + "！"
结束

打印 问候("小明")           # 同学，你好，小明！
打印 问候("小红", "老师")   # 老师，你好，小红！
```

**可变参数**：`...名字` 把多余实参收集成列表：

```text
函数 求和(首项: 整数, ...其余) -> 整数
  变量 总和 = 首项
  对于 下标 = 1 到 列表长度(其余)
    总和 = 总和 + 列表取整数(其余, 下标 - 1)
  结束
  返回 总和
结束

打印 求和(1, 2, 3, 4, 5)   # 15
```

## 8. 闭包与函数值

函数是「一等值」：可以赋给变量、当参数传递、作为返回值。

**匿名函数**：`(参数: 类型) => 表达式`，自动按值捕获外层变量：

```text
变量 系数 = 3
变量 三倍 = (x: 整数) => x * 系数
打印 三倍(5)      # 15
```

**函数返回函数**：

```text
函数 造加器(加数: 整数) -> 函数
  返回 (x: 整数) => x + 加数
结束

变量 加五 = 造加器(5)
打印 加五(100)    # 105
```

**命名函数也能当值用**：

```text
函数 翻倍(数: 整数) -> 整数
  返回 数 * 2
结束

变量 算子 = 翻倍
打印 算子(21)     # 42
```

注意：被捕获的变量按「创建时的值」快照保存，之后不能再对它赋值（编译期会报错提醒）。

## 9. 列表与字典

**列表**——有序集合，下标从 0 开始：

```text
变量 水果 = ["苹果", "香蕉", "橘子"]
列表新增(水果, "西瓜")
打印 列表长度(水果)          # 4
打印 列表取文字(水果, 0)     # 苹果
列表设(水果, 1, "葡萄")
列表删除(水果, 0)
```

**字典**——字符串键的键值对，支持字面量与「.名字」成员糖：

```text
变量 人 = {名字: "小明", 年龄: 18}
打印 人.年龄              # 18
人.年龄 = 19              # 成员写
打印 字典取文字(人, "名字")  # 小明（文字成员用类型化访问器）
打印 字典长度(人)
```

提示：`表.名` 读取结果的类型是「未知」，整数值可直接打印；文字、列表等成员请用 `字典取文字` 等类型化访问器。

**小数元素**用专用访问器读取，避免把 double 位模式当成整数：

```text
变量 分数 = [1.5, 2.5]
打印 列表取数(分数, 0)          # 1.5
列表设(分数, 0, 3.5)
变量 体测 = {身高: 1.75}
打印 字典取数(体测, "身高")     # 1.75
```

## 10. 模块与导入

把公共函数放进独立文件，用 `导入` 引用（路径相对当前文件）：

```text
# 工具.汉
函数 问好(名字: 文字) -> 文字
  返回 "你好，" + 名字 + "！"
结束
```

```text
# 主程序.汉
导入 "工具.汉"

打印 问好("世界")
```

同一文件多次导入只展开一次；模块顶层的语句在导入处按顺序执行一次。

## 11. 文字、输入、文件与时间

```text
打印 文字长度("汉语言，你好")    # 6（按字符数）
打印 文字子串("汉语言，你好", 0, 3)
打印 文字包含("汉语言，你好", "你好")
打印 文字转整数("42") + 8

写文件("笔记.txt", "第一行\n")
追加文件("笔记.txt", "第二行\n")
打印 读文件("笔记.txt")

打印 现在()          # 本地时间文字
打印 现在毫秒()      # 自 1970 起的毫秒数
```

**键盘输入**——程序可以停下来等你敲一行字再按回车：

```text
打印 "你叫什么名字？"
变量 名字 = 输入文字()       # 读一行文字
打印 "你好，" + 名字 + "！"

变量 年龄 = 输入整数()       # 读一行并解析为整数
变量 身高 = 输入数()         # 读一行并解析为小数
打印 文字转数("2.5") + 1     # 文字转小数：3.5
```

编译出的 exe 直接双击运行即可：程序结束时窗口会显示「按回车键退出」，
不会再一闪而过。在编辑器里按 F5 也会弹出独立的运行窗口，可以正常输入。
完整的交互示例见 `examples/09-猜数字.汉`。

完整标准库清单见 `doc/语言规范.md` 第 13.6 节。
