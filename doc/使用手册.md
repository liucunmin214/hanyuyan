# 汉语言使用手册

> han.exe（编译器）与 hanedit.exe（代码编辑器）的完整使用说明与常见问题。

## 一、编译器 han.exe

### 1.1 基本用法

```text
han.exe <选项> <源文件.汉>
han.exe 我的程序.汉 -o 我的程序.exe
```

不带 `-o` 时，输出与源文件同名同目录的 `.exe`。产物是**独立 Windows 可执行文件**：仅依赖系统自带的 kernel32.dll，无 CRT、无运行时 DLL，可直接拷贝给其他 Windows 机器运行。

### 1.2 选项一览

| 选项 | 作用 |
|---|---|
| `-o <文件>` | 指定输出可执行文件路径 |
| `--check` | 只做语法与语义检查，不产出 exe（快速查错） |
| `--dump-tokens` | 输出词法记号流（调试用） |
| `--dump-ast` | 输出抽象语法树（调试用） |
| `--dump-ir` | 输出中间表示 IR（调试用） |

退出码：`0` 成功；`1` 编译错误（诊断输出到标准输出/错误）。

### 1.3 诊断格式

```text
文件:行:列: 错误: 消息
  源码行
      ^
```

行列均从 1 起，列按字符计（一个汉字占一列）。编辑器可解析此格式实现错误跳转。

### 1.4 多文件项目

主文件用 `导入 "相对路径.汉"` 引用其他模块，编译器自动递归展开、去重并检测循环导入，只需对主文件执行一次编译。

## 二、编辑器 hanedit.exe

### 2.1 界面组成

- **编辑区**（上）：语法高亮——关键字蓝、类型紫、字符串橙、数字青、注释绿
- **输出面板**（下）：显示编译与运行输出；错误行标红、成功行标绿；拖动中间分割线可调整高度
- **状态栏**：分三段显示光标行列、文件编码、编译器是否已就绪

### 2.2 菜单与快捷键

| 功能 | 快捷键 |
|---|---|
| 新建 / 打开 / 保存 | Ctrl+N / Ctrl+O / Ctrl+S |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| **编译并运行** | **F5** |
| 仅语法检查 | F6 |
| 打开教程 | F1 |

### 2.3 编译运行流程（F5）

1. 自动保存当前文件（未命名文件会先要求选择保存位置）
2. 自动定位 `han.exe` 并编译为源文件同目录的同名 `.exe`
   （定位顺序：编辑器同目录 → 上次记住的位置 → 系统 PATH → 安装目录 → 常见安装位置 → 手动选择）
3. 编译输出显示在输出面板；**双击错误行可跳转到源码对应行列**
4. 编译成功后在**独立控制台窗口**中运行程序：可以正常键盘输入（`输入文字()` 等），
   程序结束时窗口自动暂停并提示「按回车键退出」，不会一闪而过
5. 运行窗口由你自行关闭，编辑器不会终止它

### 2.4 其他使用要点

- **打开文件**：菜单/快捷键、把 `.汉` 文件拖进窗口、或命令行 `hanedit.exe 文件.汉`
- **文件编码**：一律以 UTF-8 读写（保存不含 BOM）；打开非 UTF-8 文件会报错
- **修改标记**：标题栏文件名后的 `*` 表示有未保存修改
- **依赖**：F5/F6 需要 `han.exe`。编辑器会自动定位（同目录 / 记忆位置 / PATH / 安装目录 / 常见位置），
  都找不到时会弹出手动选择框，也可用菜单「帮助 → 设置编译器位置…」随时指定
- **帮助**：F1 打开 HTML 教程；「帮助 → 打开使用手册」打开本手册；
  教程与手册会自动在「安装目录\doc」或绿色版「build\..\doc」下查找

## 三、常见问题（FAQ）

**问：双击 `han.exe` 一闪而过？**
`han.exe` 是命令行编译器，双击它等于「不带参数编译」。现在它也会打印用法并等待回车，
不会再闪退。要运行程序，请双击**编译出来的** exe，或用编辑器的 F5。

**问：最简单的一键用法是什么？**
命令行里只给文件、不带任何选项：

```powershell
han.exe 我的程序.汉
```

编译器会把 exe 生成到**源文件同目录**（代码保存在任何位置都可以），
并自动弹出独立窗口运行——可键盘输入，结束自动暂停。
带 `-o` 等选项时只编译不自动运行，方便脚本和编辑器使用。

**问：双击编译出的 exe 一闪而过，看不清输出？**
已解决：程序结束时会先显示「── 程序结束，按回车键退出 ──」并等待回车。
只有在从已有终端或管道启动时才不暂停，方便脚本化使用。

**问：PowerShell 里运行程序，中文输出是乱码？**
程序输出本身是 UTF-8。PowerShell 5 的控制台代码页可能造成显示乱码，先执行 `chcp 65001` 或改用编辑器 F5 运行（独立窗口自动设为 UTF-8，无此问题）。

**问：程序里怎么从键盘读输入？**
用标准库 `输入文字()`、`输入整数()`、`输入数()`，各读一行。示例见 `examples/09-猜数字.汉`。

**问：编译出的 exe 被杀毒软件拦截？**
自研链接器产出的 PE 文件结构较特殊，可能触发个别杀软启发式误报，加入信任区即可。程序无任何网络与系统修改行为。

**问：可以导入中文路径/中文文件名的模块吗？**
可以。源文件路径、模块路径都支持中文（编译器内部自动处理编码转换）。

**问：为什么 `表.名` 打印出来是数字而不是文字？**
`表.名` 读取结果类型为「未知」，按整数打印。文字成员请用 `字典取文字(表, "名")`。

**问：被闭包捕获的变量为什么不能修改？**
闭包按「创建时的值」快照捕获（按值捕获），为保证语义清晰，创建后禁止对原变量赋值。需要可变状态时，把数据放进列表或字典再捕获容器。

**问：标准库分配的内存会释放吗？**
当前版本内存只分配不释放，适合短生命周期的工具与教学程序；长跑服务类程序请留意内存占用。

**问：编辑器提示「未找到 han.exe（编译器）」怎么办？**
先确认已安装汉语言（或已运行 `build.ps1` 生成 `build\han.exe`）。编辑器会自动依次查找：
同目录 → `%APPDATA%\汉语言\compiler.ini` 记住的位置 → 系统 PATH → 安装目录 → 常见安装位置；
都找不到时按 F5 会弹出手动选择框，选中 `han.exe` 后会自动记住。
也可随时用菜单「帮助 → 设置编译器位置…」指定或更换。

**问：按 F1 打不开教程？**
编辑器会自动在 `安装目录\doc\教程\教程.html`、绿色版 `build\..\doc\教程\教程.html`
以及编译器所在目录的 `doc\` 下查找（找不到 HTML 时回退 `教程.md`）。
若仍提示未找到，说明安装不完整，请重新运行安装包；也可以从开始菜单「汉语言教程」打开。

**问：支持哪些还没实现的功能？**
`从` 选择性导入、按引用捕获、`表.名(...)` 形式的方法调用暂不支持，详见 `项目进度.md` 的已知限制。

## 四、安装与卸载

安装包 `汉语言安装包.exe` 由 Inno Setup 7 生成，简体中文向导：

- 默认安装到 `%LOCALAPPDATA%\Programs\汉语言`（无需管理员权限，也可自行改目录）
- 可选：创建桌面快捷方式、把安装目录加入用户 PATH、把 `.汉` 文件关联到编辑器
- 开始菜单含「汉语言编辑器」「汉语言教程」「卸载汉语言」
- 安装完成后可直接勾选启动编辑器；教程与示例在安装目录的 `doc\` 与 `examples\`

卸载：开始菜单「卸载汉语言」，或「设置 → 应用」，卸载会删除安装目录与开始菜单项，
并清理安装时写入的用户 PATH 与文件关联。

也可以不用安装包：把 `build\han.exe` 与 `build\hanedit.exe` 放到任意目录，直接运行编辑器即可。
