# 汉语言

> 一门用中文写代码的静态类型编译型编程语言。

汉语言让你用自然的中文书写程序，编译器从词法分析到 x86-64 机器码生成全部自研，产出**不依赖任何运行时的独立 Windows exe**。

```text
打印 "你好，汉语言！"
```

## ✨ 特性

- **中文关键字 + 同义词**：`打印`/`输出`/`显示`、`变量`/`令`、`如果`/`若`……怎么顺手怎么写
- **全角标点自动归一**：`，。（）：「」`等中文标点直接写，编译器自动识别
- **中文标识符**：变量名、函数名可用汉字，如`变量 计数器 = 0`
- **静态类型 + 类型推断**：编译期类型检查，大多数情况可省略类型标注
- **真正的编译**：自研前端 + 自研 x86-64 后端，生成独立 exe，无需安装运行时
- **块用「结束」收尾**：不用大括号，`如果`、`当`、`函数`一律以`结束`结束
- **函数一等值**：递归、默认参数、可变参数、闭包与匿名函数
- **内置标准库**：文字、列表、字典、文件、时间、数学等常用函数
- **多文件导入**：`导入`关键字组织模块化代码
- **自带图形编辑器**：纯 Win32 编写的代码编辑器，语法高亮、F5 编译运行、错误跳转

## 🚀 快速开始

### 下载安装

从 [Release](https://github.com/liucunmin214/hanyuyan/releases) 下载安装包 `hanyuyan_setup.exe`，双击安装即可（免管理员权限，自动加入 PATH、关联 `.汉` 文件）。

### 第一个程序

新建文件 `你好.汉`，输入：

```text
打印 "你好，汉语言！"
```

**图形方式**（推荐新手）：打开 `hanedit`，写好代码按 **F5** 编译运行。

**命令行方式**：

```bash
han 你好.汉 -o 你好.exe
你好.exe
```

## 📖 语言速览

### 变量与类型

```text
变量 甲 = 10              # 推断为「整数」
变量 乙: 小数 = 2.5       # 显式标注类型
常量 圆周率 = 3.14159     # 常量不可重新赋值
```

五种基本类型：`整数`、`小数`、`文字`、`布尔`（`真`/`假`）、`空`。

### 控制流

```text
如果 分数 >= 90
  打印 "优秀"
结束
否则
  打印 "继续加油"
结束

当 i < 10
  打印 i
  令 i = i + 1
结束
```

### 函数

```text
函数 阶乘(n: 整数): 整数
  如果 n <= 1
    返回 1
  结束
  返回 n * 阶乘(n - 1)
结束

打印 阶乘(5)   # 120
```

### 闭包

```text
函数 累加器(初始值: 整数)
  变量 总和 = 初始值
  返回 函数(增量: 整数)
    令 总和 = 总和 + 增量
    返回 总和
  结束
结束

变量 计 = 累加器(10)
打印 计(5)    # 15
打印 计(3)    # 18
```

## 🏗️ 从源码构建

项目使用纯 C11 编写，无第三方依赖。构建工具链为 [w64devkit](https://github.com/skeeto/w64devkit)（gcc 16，mingw-w64）。

```powershell
# 一键构建编译器、运行时、编辑器，并运行全部测试
.\build.ps1 -Test
```

构建产物在 `build/` 目录：

- `build/han.exe` — 命令行编译器
- `build/hanedit.exe` — 图形代码编辑器

### 项目结构

```text
汉语言/
├── src/              # 编译器源码
│   ├── lexer/        # 词法分析（关键字、全角归一、UTF-8）
│   ├── parser/       # 递归下降语法分析 + AST
│   ├── sema/         # 语义分析、类型检查、符号表
│   ├── ir/           # 三地址码中间表示 + 常量折叠
│   ├── backend/      # 自研 x86-64 指令选择 + 寄存器分配
│   ├── coff/         # COFF 目标文件读取
│   ├── link/         # 自研 PE 链接器
│   └── util/         # 内存池、向量、诊断、UTF-8 工具
├── runtime/          # freestanding 运行时（无 CRT）
├── editor/           # Win32 图形代码编辑器
├── tests/            # 单元测试 + 端到端测试
├── examples/         # 示例程序
├── doc/              # 语言规范、教程、使用手册
└── installer/        # Inno Setup 安装包脚本
```

### 编译流水线

```
源文件(.汉) → 词法分析 → 语法分析(AST) → 语义/类型检查 → IR(三地址码) → x86-64 指令选择 → PE 链接 → 独立 exe
```
